# AboGator · Frontend

Aplicación móvil y de tablet (Flutter) de AboGator, el motor educativo LawSwipe: tarjetas deslizables para aprender Derecho Informático.

Este repositorio contiene solo el frontend. El backend y la base de datos viven en repositorios aparte y los desarrollan otras personas del equipo.

La documentación de trabajo está en `ai/conocimiento/`.
